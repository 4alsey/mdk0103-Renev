Туристические путёвки — консольное приложение (Java)
Консольное приложение для подбора туристических путёвок разных типов (отдых, экскурсии, лечение, шопинг, круиз и т. д.) с учётом транспорта, питания и количества дней. Реализованы выбор (фильтрация) и сортировка путёвок.

Возможности
Просмотр всех доступных путёвок
Фильтрация:
по типу тура
по транспорту
по диапазону дней
Сортировка:
по цене (возрастание)
по количеству дней (возрастание)
Бронирование выбранной путёвки (демонстрация полиморфизма через интерфейс)
ООП (по заданию)
В проекте используются:

классы и иерархия по предметной области
абстрактный класс базовой путёвки
интерфейс (для операции бронирования)
наследование (только где имеет смысл: конкретные типы туров от базового тура)
полиморфизм (обработка разных туров через общий тип/интерфейс)
инкапсуляция (приватные поля + get/set)
методы setType()/getType(), toString(), equals() реализованы в базовой модели тура
Структура проекта
src/Main.java — точка входа, консольное меню (выбор/фильтрация/сортировка)
src/travel/ — доменная модель:
базовый абстрактный тур и конкретные типы туров
перечисления Transport, MealPlan, TourType
интерфейс Bookable
Требования
JDK 17+ (подойдёт и 11+, если у вас нет новых возможностей Java; но рекомендуется 17+)
Windows + PowerShell (или любой терминал)
Проверить установленный компилятор:
javac -version
Как скомпилировать и запустить (PowerShell)
Откройте PowerShell в корне проекта (где папка src) и выполните:

Компиляция
javac -encoding UTF-8 -d out src\Main.java src\travel*.java
Запуск
java -cp out Main
Как пользоваться
После запуска появится меню. Введите номер пункта меню и нажмите Enter:
показать все путёвки
применить фильтры (тип/транспорт/дни)
выполнить сортировку (цена/дни)
выбрать и «забронировать» тур
